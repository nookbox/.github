### nookbox란?

nook은 구석진 공간을 뜻합니다.<br/>
제가 생각하기에 구석진 공간은, 어두워서 손으로 더듬어야 하는 자리입니다. 대신 무엇을 만졌는지는 남는다고 생각합니다.<br/>
제 의지가 담긴 코드 한줄을 남기고 결과물을 남기는 공간입니다.


### 왜 만들었나요?

토마스 모어는 『유토피아』에서 인클로저를 이렇게 표현했습니다.

> 온순하던 양이 이제는 사람을 잡아먹는다.

양을 치는 쪽이 더 돈이 되자, 밭을 갈던 사람들이 땅에서 밀려났습니다. <br/>
사람을 먹이려고 기른 양이 사람을 밀어낸 셈입니다.<br/>

요즘 코드를 짜면서 비슷한 기분이 듭니다. <br/>
AI는 빠르고, 안 쓰면 뒤쳐지니까 계속 씁니다. <br/>
그러다 보니 직접 생각하는 시간이 눈에 띄게 줄었고, <br/>
코드를 어떻게 짜는지도 조금씩 잊어가는 것 같았습니다. <br/>

AI를 쓰지 않겠다는 뜻은 아닙니다. 그럴 수도 없고, 그럴 필요도 없다고 생각합니다. <br/>
다만 많은 것을 AI에게 넘기고 난 뒤에도 내게 무엇이 남아 있는지는 한 번쯤 확인해보고 싶었습니다. <br/>

그래서 이곳에서는 조금 천천히 만듭니다. <br/>
막히면 바로 답을 찾기보다 막힌 채로 조금 더 있어 보고, 이해되지 않는 것은 이해될 때까지 붙잡아 봅니다.<br/>
결과물을 빨리 완성하는 것보다 왜 이렇게 동작하는지 알고 넘어가는 것을 조금 더 중요하게 생각합니다.<br/>
