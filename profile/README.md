개인 작업 공간입니다.

### 왜 만들었나

토마스 모어는 『유토피아』에서 인클로저를 이렇게 적었습니다.

> 온순하던 양이 이제는 사람을 잡아먹는다.

양을 치는 쪽이 더 돈이 되자, 밭을 갈던 사람들이 땅에서 밀려났습니다.
사람을 먹이려고 기른 양이 사람을 밀어낸 셈입니다.

요즘 코드를 짜면서 비슷한 기분이 듭니다.
AI는 빠르고, 안 쓰면 뒤쳐지니까 계속 씁니다.
그러다 보니 직접 생각하는 시간이 눈에 띄게 줄었고,
코드를 어떻게 짜는지도 조금씩 잊어가는 것 같았습니다.

AI를 안 쓰겠다는 뜻은 아닙니다. 그럴 수도 없고요.
다만 전부 넘기고 나면 내게 뭐가 남는지는 한 번 확인해두고 싶었습니다.

여기서는 천천히 만듭니다.
막히면 막힌 채로 두고, 이해될 때까지 붙잡습니다.

### 하는 것들

만들면서 내린 결정과 그때의 생각은 각 레포의 위키에 남깁니다.
